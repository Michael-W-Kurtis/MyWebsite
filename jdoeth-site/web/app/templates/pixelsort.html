HOW TO

  1. Load a picture. Drag it onto the box or press SELECT FILE. Big images are shrunk to {{ max_dim }} px on the long edge, because the sort is a per-pixel Python loop and a full phone photo would take a minute.
  2. Pick an interval function. This decides where each sorted run starts and stops. threshold is the classic look. none sorts whole rows and melts the image completely.
  3. Pick a sorting function. This decides what order pixels land in. hue gives rainbow smears; lightness keeps the subject readable.
  4. Watch the dials appear and disappear. Only the controls that affect your current interval function are shown. Threshold sliders mean nothing to waves, so they go away.
  5. Read the command, then press SORT. What you see is what runs.

To copy the original Asendorf effect: sort once at -a 90, save the result, upload it again, and sort at -a 0.
