HOW TO

  1. This renders at full size. Nine or sixteen complete images, not previews. A 3 MP photo takes about a minute for sixteen cells; a large one takes several. The estimate before you press render is calculated from your image, not a guess.
  2. MATRIX crosses every interval function with every sorting function. Start here if you don't know what you want — it shows the widest range in one screen.
  3. INTENSITY locks one interval and sorting function, then ramps two parameters so the effect grows toward the bottom right. Top left is the subtlest render, bottom right the most extreme.
  4. SWEEP steps a single parameter across every cell. Use it once you know the look and want to dial in one number.
  5. Corners render first, then the diagonal, then the rest — so you see the extremes of both axes early and can stop a batch that isn't working.
  6. Click any cell for the full-resolution image and its exact command. The grid shows scaled-down copies so the browser doesn't have to hold sixteen full-size bitmaps at once; the download is always the real thing.

Reloading is safe. Finished cells are cached on disk, so coming back to this page's address brings them straight back and only the unfinished ones re-render.
